Available Commands

  • "Read text" — capture and read text aloud (auto-starts the camera)
  • "Start navigation" — switch to navigation mode (auto-starts the camera)
  • "Detect objects" — switch to object detection mode
  • "Stop speaking" — interrupt current speech
  • "Repeat" — say the last announcement again
  • "Describe the scene" — summarize what's currently detected
  • "Where is my <object>" — e.g. "where is my bag" (answers from recent memory)
  • "Exit" — stop the voice assistant

🖐️ These same actions are also available as hand gestures on the Live Camera page (enable "Gesture Control"): fist = toggle detection, open palm = stop speaking, peace sign = read text, one finger = describe scene, thumbs up = repeat.
