About This Project

AI-Based Object and Text Detection for Visually Impaired People is a final-year engineering project that combines computer vision and offline speech synthesis to help visually impaired users understand their surroundings.

How It Works

  • YOLOv8 detects objects in the live camera feed in real time.
  • EasyOCR extracts printed text from captured frames.
  • pyttsx3 converts results to speech completely offline.
  • Navigation logic estimates obstacle position (left/center/right) from bounding boxes.
  • SpeechRecognition powers hands-free voice commands.

Bonus Features

  • Dominant color detection for detected objects
  • Heuristic currency note recognition (extensible with a trained model)
  • QR code scanning
  • Emergency SOS alert button
  • GPS placeholder for location sharing
  • Battery saver / performance mode

Tech Stack

  • Backend: Python, Flask
  • AI: YOLOv8 (Ultralytics), EasyOCR, OpenCV, pyttsx3, SpeechRecognition
  • Frontend: HTML, CSS, JavaScript (responsive, accessibility-first UI)

Disclaimer

This is an academic prototype. Distance/navigation guidance is heuristic (monocular, no depth sensor) and should not be relied upon as a sole mobility aid.
