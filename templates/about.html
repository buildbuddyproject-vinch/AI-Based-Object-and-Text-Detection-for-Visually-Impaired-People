About This Project

AI-Based Object, Text, Currency and Navigation Assistant for Visually Impaired People is a final-year engineering project that combines computer vision and offline speech synthesis to help visually impaired users understand their surroundings. It is voice-first and buttonless by design - running python app.py starts the camera, text-to-speech, and microphone automatically; every page on this site (other than this one) is an optional developer/debugging view, not a requirement for the assistant to work.

How It Works

  • Domain-specific YOLOv8 models (indoor, household - trained on this project's own real datasets, not a generic model) detect objects in the live camera feed.
  • Temporal confirmation requires an object to be seen consistently across several frames before it's ever announced, filtering out single-frame misreads.
  • A priority engine picks the single most relevant thing to mention - never a running list of every object in view.
  • Footpath detection estimates which of Left/Center/Right is walkable, where trained data supports it.
  • EasyOCR extracts printed text on demand ("read this").
  • pyttsx3 converts results to speech completely offline.
  • SpeechRecognition powers hands-free voice commands.

What This Project Deliberately Does NOT Do

  • No face recognition or identity of any kind. The system can say "Person ahead." - it will never say a name.
  • No silent fallback to a generic model. A domain with no trained model honestly reports itself unavailable rather than guessing with mismatched weights.
  • No fabricated confidence. Uncertain detections are reported as "Object not clearly recognized," never a confident-sounding wrong guess.

Bonus Features

  • Dominant color detection for detected objects
  • ORB feature-matching currency note recognition against real reference images
  • QR code scanning
  • Emergency SOS alert (simulated)
  • Real GPS location, reported by the browser's own Geolocation API
  • Battery saver / performance mode

Tech Stack

  • Backend: Python, Flask
  • AI: YOLOv8 (Ultralytics), EasyOCR, OpenCV, pyttsx3, SpeechRecognition
  • Frontend: HTML, CSS, JavaScript (responsive, accessibility-first UI)

Disclaimer

This is an academic prototype. Distance/navigation guidance is heuristic (monocular, no depth sensor) and should not be relied upon as a sole mobility aid. See README.md's Final Status Report for real, measured accuracy numbers and known limitations - nothing here is claimed without having been tested.
